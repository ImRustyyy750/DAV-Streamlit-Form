This is a simple streamlit form created in python using Streamlit. It contains essential validation rules in the form. The main form file (DAV_Reg.py) saves the data to an external csv. This was possible here through github tokens or else the alternative was to use an database. 
Pandas were used for all the dataframe related codes, plotly was obviously used for the graphs and charts in Admin.py. Base64, requests, iostring is only there so that the file can save data in github csv.
